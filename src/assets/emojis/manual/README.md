# Manual emoji art

These PNGs and GIFs have no generation script. They are hand-maintained,
exported from Discord, game sprites, or legacy art that has not been replaced.

The sync uploads them by filename; nothing in `scripts/` writes to this folder.
When adding art here, add the emoji to `src/config/emojis.py` first, then run
the normal sync. Animated files keep the animated flag from the config.
