# Emoji review

These PNGs were generated by the old Lucide / Simple Icons / Web3 Icons /
Phosphor tables, but they have no clean equivalent in the With Icons families.
They are deliberately kept out of `seasonal/` so the generator never overwrites
them. The emoji sync still resolves and uploads them, so the bot keeps working
while each family is reviewed.

| Family | Count | Existing source | Why it is here |
| --- | ---: | --- | --- |
| `general` | 3 | Lucide / custom glyphs | With Icons has no clean paddle, theatre or memory-stick mark. |
| `log` | 8 | Lucide | With Icons has no plus/x/check ticket, tag-plus/x/tags or badge-help marks; forcing one would make unrelated log headings share or misread an icon. |
| `brand` | 15 | Simple Icons | With Icons ships UI artwork, not brand marks. The existing Simple Icons art is kept until a brand source is chosen. |
| `crypto` | 8 | Web3 Icons (mono) | With Icons has no cryptocurrency family; one coin would break the one-family rule for the payment row. |
| `number` | 10 | Phosphor Icons (bold) | With Icons has no plain 0-9 digits, and a different digit family would be visibly inconsistent in paginators and help lists. |

## Decision

For each family, either:

- map it to a reviewed With Icons icon and move the PNG into
  `seasonal/default/` (and add the seasonal variants if wanted), or
- keep the existing source and move the PNG into `manual/`, updating
  `scripts/build-emoji-icons.mjs` so it is not listed as review art.

`manifest.json` is the machine-readable copy of this table.
